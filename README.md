# NevAI PWA – Installable AI Chat Application

NevAI PWA is the Progressive Web App version of NevAI, a privacy-focused, client-side AI chat application powered by Groq API.

This version is optimized for:

- Mobile-first experience  
- Installability (Add to Home Screen)  
- Offline-ready architecture  
- App-like performance  
- Clean and responsive UI

## 📱 What Makes This Version Different?

NevAI PWA is not just a responsive website.

It includes:

- Web App Manifest  
- Service Worker support  
- Installable application behavior  
- Standalone display mode  
- Mobile-optimized layout  
- Touch-friendly interface  

Users can install it like a native mobile app without downloading from an app store.

---

## 🧠 Project Philosophy

The goal of NevAI PWA is to demonstrate:

- Progressive enhancement  
- Client-side AI integration  
- Privacy-first design  
- Zero backend dependency  
- Cross-platform accessibility  

This application runs entirely in the browser and communicates directly with Groq API using the user’s own API key.

---

## ⚙️ How It Works

1. User obtains an API key from Groq Console  
2. User enters the API key inside the app  
3. The browser sends requests directly to Groq API  
4. Responses are rendered in a structured chat interface  
5. The app can be installed on mobile or desktop  

No server, no database, no user tracking.

---

## 🔑 Getting a Groq API Key

1. Visit: https://console.groq.com/keys  
2. Create or sign in to your account  
3. Generate a new API key  
4. Paste it inside the NevAI PWA interface  

⚠️ API keys are never stored on a remote server.

## 🏗 Architecture Overview

User Device  
→ PWA Shell  
→ Fetch Request  
→ Groq API  
→ JSON Response  
→ UI Rendering  

The Service Worker handles:

- Static asset caching  
- Faster reloads  
- Offline shell behavior
